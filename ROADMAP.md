# Roadmap

The roadmap keeps the starter focused on being useful, reusable, and easy to deploy for Indonesian UMKM businesses.

## Phase 1 — Foundation

- [x] React + TypeScript foundation
- [x] Responsive layout system
- [x] Config-driven business information
- [x] Reusable sections and UI primitives
- [x] WhatsApp CTA integration
- [x] SEO-ready metadata and structured data
- [x] Accessibility baseline

## Phase 2 — Developer Experience

- [x] Quick start documentation
- [x] Full project documentation
- [x] Contribution guidelines
- [x] AI agent instructions
- [x] Development workflow
- [x] Architecture decision log
- [x] Practical SEO guide

## Phase 3 — Reusability

- [ ] Add more business presets
- [ ] Create theme presets for different industries
- [ ] Add stronger typed configuration validation
- [ ] Improve image/content replacement workflow
- [ ] Add a one-command business setup flow

## Phase 4 — Production Quality

- [ ] Automated CI checks
- [ ] Automated accessibility testing
- [ ] Lighthouse performance checks
- [ ] Link validation
- [ ] Visual regression testing
- [ ] Production deployment example

## Phase 5 — Community

- [ ] Collect community feedback
- [ ] Accept business-specific improvements
- [ ] Publish customization examples
- [ ] Add contribution examples
- [ ] Showcase real-world implementations

## Guiding Principle

> Build the smallest useful system first, then improve it based on real usage.
